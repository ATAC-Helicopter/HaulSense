Indicator calibration

On independent revisions, left requests 4 → 4+5 and right 2 → 2+1. Swap reverses those masks. Known standard generations 4/5 have mirrored inner and outer pairs: individual turns use HUD arrows only, while white LEDs show truck lights and hazards. Unknown revisions and Edge need physical verification.

Player LED commands are sent only when their mask changes; unrelated rumble and RGB updates do not restart the LED animation. To verify individual LEDs, stop the service and run haulsense --led-test. The tool requests each LED bit, then clears them; mirrored hardware lights a pair for each outer bit.

What the SDK can tell us

Wiper telemetry is an on/off state, so its optional tactile cue uses a gentle synthetic rhythm. Brake texture is pedal/deceleration feedback; it does not claim to detect ABS. Compatible rumble is supported; USB audio haptics are not implemented.
